#### Рекуррентное соотношение для предложенной матрицы:  
## $X_{n} = 5 * X_{n-1} - 6 * X_{n-2}$  

Характеристическое уравнение:  
$\lambda^2 = 5\lambda - 6$  
$\lambda^2 - 5\lambda + 6 = 0$  

Применяем теорему Виета:  
$\lambda_1 + \lambda_2 = 5$  
$\lambda_1 * \lambda_2 = 6$

Решение:  
$\lambda_1 = 2$  
$\lambda_2 = 3$  

$\lambda_1!=\lambda_2 =>$ Формула общего решения будет иметь вид:  
$X_n = A_1 * \lambda_1^n + A_2 * \lambda_2^n$  
$X_n = A_1 * 2^n + A_2 * 3^n$  

## $X_n = 2^n * A_1 + 3^n * A_2$  

$X_1 = 2^1 * A_1 + 3^1 * A_2$  
$X_2 = 2^2 * A_1 + 3^2 * A_2 = 4 * A_1 + 9 * A_2$  

Считаем определители 1го и 2го порядка по формуле:  
$X_1 = a = 5$  
$X_2 = a * a - b * c = 5*5 - 2 * 3 = 25 - 6 = 19$  

Составляем и решаем систему уравнений для $A_1$ и $A_2$:  
$2A_1 + 3A_2 = 5$  
$4A_1 + 9A_2 = 19$  

$2 * A_1 = -4$  
$A_1 = -\frac{4}{2} = -2$  

$3 * A_2 = 9$  
$A_2 = \frac{9}{3} = 3$  

Решение:  
$A_1 = -2$  
$A_2 = 3$

$X_n = 2^n * (-2) + 3^n * 3 =-2^{n+1}+3^{n+1}$

## Формула общего решения:  
## $X_n=3^{n+1} - 2^{n+1}$  

Проверка:  
По общей формуле рекуррентного соотношения для данной матрицы:  
$X_3 = a * X_2 - bc * X_1 = 5 * 19 - 2 * 3 * 5 = 95 - 30 = 65$  
Методом разложения по строке:  
$X_3 = a(a^2-bc) - bca = a^3 - 2abc = 5^3 - 2 * 5 * 2 * 3  = 65$  
По полученной Формуле общего решения:    
$X_3 = 3^{3+1} - 2^{3+1} = 3^4 - 2^4 = 81 - 16 = 65$
