### 4. Ответ.
Максимально возможная сумма прибыли: **29 Coin.**
  
Чтобы понять, как вложенные Coin распределены по проектам, посмотрим в последнюю таблицу.  

- Столбец ABCD, строка 100: для получения прибыли в 29 вложено **80 в D**;
- Столбец ABC, строка 20 (т.к. от исходной суммы вложений в 100 осталось только 20): вложено **0 в C**;
- Столбец AB, строка 20: вложено **20 в B**;
- Всё, что возможно было вложить израсходовано: вложено **0 в A**.  

Таким образом распределение:  
**A - 0 Coin; B - 20 Coin; C - 0 Coin; D - 80 Coin.**
