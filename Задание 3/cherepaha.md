# Задание №3
## Задача о распределении инвестиций между проектами

### Вариант 2. Команда cherepaha.

## Условие

Есть 500 монет и проекты $A$, $B$, $C$, $D$, вкладывать можно порциями по 100, вложить нужно всё.

| Вложили, монет | $A$ | $B$ | $C$ | $D$ |
|---|---|---|---|---|
| 100 | 5 | 3 | 5 | 4 |
| 200 | 10 | 7 | 8 | 8 |
| 300 | 15 | 8 | 18 | 14 |
| 400 | 20 | 10 | 21 | 19 |
| 500 | 21 | 22 | 25 | 26 |

Число - выплата за всю сумму сразу. «100 в $A$ и ещё 100 в $A$» - это просто 200 в $A$, то есть 10, а не $5+5$.

## Метод

Делить сразу на четыре проекта сложно, вариантов много. Поэтому подключаем проекты по одному: сначала разбираемся, как лучше делить деньги между $A$ и $B$, потом добавляем $C$, потом $D$. Получается три шага.

Для каждой суммы перебираем все способы её распределить между агрегатом и новым проектом и выбираем наибольшую выплату. Всё, что не пошло в новый проект, автоматически уходит в агрегат. Вместе с максимумом записываем, сколько монет ушло в текущий проект: `23 (100)` - максимальная выплата 23, в текущий проект 100. Эти пометки понадобятся в самом конце для обратного хода.

## Шаг 1. Делим между $A$ и $B$

Пока забываем про $C$ и $D$, как будто проектов всего два.

```text
100 монет
  A 100 + B 0    →   5 + 0  =  5   ← максимум
  A 0   + B 100  →   0 + 3  =  3
  запись: 5 (0)

200 монет
  A 200 + B 0    →  10 + 0  = 10   ← максимум
  A 100 + B 100  →   5 + 3  =  8
  A 0   + B 200  →   0 + 7  =  7
  запись: 10 (0)

300 монет
  A 300 + B 0    →  15 + 0  = 15   ← максимум
  A 200 + B 100  →  10 + 3  = 13
  A 100 + B 200  →   5 + 7  = 12
  A 0   + B 300  →   0 + 8  =  8
  запись: 15 (0)

400 монет
  A 400 + B 0    →  20 + 0  = 20   ← максимум
  A 300 + B 100  →  15 + 3  = 18
  A 200 + B 200  →  10 + 7  = 17
  A 100 + B 300  →   5 + 8  = 13
  A 0   + B 400  →   0 + 10 = 10
  запись: 20 (0)

500 монет
  A 500 + B 0    →  21 + 0  = 21
  A 400 + B 100  →  20 + 3  = 23   ← максимум
  A 300 + B 200  →  15 + 7  = 22
  A 200 + B 300  →  10 + 8  = 18
  A 100 + B 400  →   5 + 10 = 15
  A 0   + B 500  →   0 + 22 = 22
  запись: 23 (100)
```

Почти везде выгоднее всё отдать в $A$. Интересна только сумма 500: всё в $A$ даёт 21, всё в $B$ - 22, а лучше всего 400 в $A$ и 100 в $B$: $20 + 3 = 23$.

```text
сумма       100   200   300   400   500
AB            5    10    15    20    23
в B           0     0     0     0   100
```

Дальше можно не думать, как именно деньги делятся внутри: $AB$ становится как бы одним проектом. Даёшь ему сумму - он возвращает лучшее, что могут $A$ и $B$ вместе.

## Шаг 2. Подключаем $C$

Делаем то же самое, только теперь делим деньги между «проектом» $AB$ и проектом $C$. Сколько вернёт $AB$, смотрим в итоге шага 1, сколько вернёт $C$ - в таблице условия. В скобках пишем, сколько ушло в $C$.

```text
100 монет
  AB 100 + C 0    →   5 + 0  =  5   ← максимум
  AB 0   + C 100  →   0 + 5  =  5   ← тоже максимум
  запись: 5 (0)

200 монет
  AB 200 + C 0    →  10 + 0  = 10   ← максимум
  AB 100 + C 100  →   5 + 5  = 10   ← тоже максимум
  AB 0   + C 200  →   0 + 8  =  8
  запись: 10 (0)

300 монет
  AB 300 + C 0    →  15 + 0  = 15
  AB 200 + C 100  →  10 + 5  = 15
  AB 100 + C 200  →   5 + 8  = 13
  AB 0   + C 300  →   0 + 18 = 18   ← максимум
  запись: 18 (300)

400 монет
  AB 400 + C 0    →  20 + 0  = 20
  AB 300 + C 100  →  15 + 5  = 20
  AB 200 + C 200  →  10 + 8  = 18
  AB 100 + C 300  →   5 + 18 = 23   ← максимум
  AB 0   + C 400  →   0 + 21 = 21
  запись: 23 (300)

500 монет
  AB 500 + C 0    →  23 + 0  = 23
  AB 400 + C 100  →  20 + 5  = 25
  AB 300 + C 200  →  15 + 8  = 23
  AB 200 + C 300  →  10 + 18 = 28   ← максимум
  AB 100 + C 400  →   5 + 21 = 26
  AB 0   + C 500  →   0 + 25 = 25
  запись: 28 (300)
```

```text
сумма       100   200   300   400   500
ABC           5    10    18    23    28
в C           0     0   300   300   300
```

## Шаг 3. Подключаем $D$

$D$ - последний проект, поэтому считаем только для всех 500 монет. Меньшие суммы пригодятся, только если после $D$ будет ещё один проект: он спросит у нас результаты этого шага для разных сумм, а следующего проекта нет.

```text
500 монет
  ABC 500 + D 0    →  28 + 0  = 28   ← максимум
  ABC 400 + D 100  →  23 + 4  = 27
  ABC 300 + D 200  →  18 + 8  = 26
  ABC 200 + D 300  →  10 + 14 = 24
  ABC 100 + D 400  →   5 + 19 = 24
  ABC 0   + D 500  →   0 + 26 = 26
  запись: 28 (0)
```

Лучшее - **28**, в $D$ ничего не идёт. Это видно и сразу: у $ABC$ на 500 монет тоже 28.

Всё вместе (в скобках - сколько ушло в последний добавленный проект):

| Монет | $A$ | $B$ | $C$ | $D$ | $AB$ | $ABC$ | $ABCD$ |
|---|---|---|---|---|---|---|---|
| 100 | 5 | 3 | 5 | 4 | 5 (0) | 5 (0) | - |
| 200 | 10 | 7 | 8 | 8 | 10 (0) | 10 (0) | - |
| 300 | 15 | 8 | 18 | 14 | 15 (0) | 18 (300) | - |
| 400 | 20 | 10 | 21 | 19 | 20 (0) | 23 (300) | - |
| 500 | 21 | 22 | 25 | 26 | 23 (100) | 28 (300) | 28 (0) |

## Обратный ход: куда вкладывать

Мы знаем, что можно получить 28, но пока не знаем как. Тут и нужны скобки. Идём с конца:

```text
500 монет, шаг 3: запись 28 (0)    →  в D 0,    осталось 500
500 монет, шаг 2: запись 28 (300)  →  в C 300,  осталось 200
200 монет, шаг 1: запись 10 (0)    →  в B 0,    значит в A все 200
```

## Ответ

Максимальная выплата при вложении 500 монет - **28 монет**. Для этого 200 монет вкладываем в $A$ и 300 в $C$, а в $B$ и $D$ ничего.

## Проверка

$A$ за 200 вернёт 10, $C$ за 300 вернёт 18, вместе $10 + 18 = 28$; вложено $200 + 300 = 500$. Сходится.

Всё в один проект дало бы максимум 26 (проект $D$), так что 28 - лучший результат; на каждом шаге максимум достигается единственным способом, вариант с 28 единственный.
