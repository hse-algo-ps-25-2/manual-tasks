# Распределение ресурсов - команда Void (вариант 8)


Распределить 500 монет между проектами A, B, C, D, E так, чтобы суммарная прибыль была максимальной. Вложения делаются кратно 100 монетам.

| Монеты | A | B | C | D | E |
|-------:|--:|--:|--:|--:|--:|
| 100 | 2 | 4 | 4 | 3 | 5 |
| 200 | 5 | 5 | 6 | 4 | 6 |
| 300 | 8 | 7 | 8 | 9 | 9 |
| 400 | 11 | 8 | 9 | 10 | 10 |
| 500 | 12 | 12 | 12 | 13 | 11 |

## Решение

### Этап 1. Проекты A и B

В ячейках: $f_B(y) + f_A(x - y)$.

| Бюджет $x$ | B = 0 | B = 100 | B = 200 | B = 300 | B = 400 | B = 500 | $F_2(x)$ | Распределение |
|-----------:|------:|--------:|--------:|--------:|--------:|--------:|---------:|:--------------|
| 100 | 2 | 4 | | | | | **4** | A = 0, B = 100 |
| 200 | 5 | 6 | 5 | | | | **6** | A = 100, B = 100 |
| 300 | 8 | 9 | 7 | 7 | | | **9** | A = 200, B = 100 |
| 400 | 11 | 12 | 10 | 9 | 8 | | **12** | A = 300, B = 100 |
| 500 | 12 | 15 | 13 | 12 | 10 | 12 | **15** | A = 400, B = 100 |

### Этап 2. Проекты A, B и C

В ячейках: $f_C(y) + F_2(x - y)$, где $F_2$ — результат этапа 1.

| Бюджет $x$ | C = 0 | C = 100 | C = 200 | C = 300 | C = 400 | C = 500 | $F_3(x)$ | Распределение |
|-----------:|------:|--------:|--------:|--------:|--------:|--------:|---------:|:--------------|
| 100 | 4 | 4 | | | | | **4** | B = 100 или C = 100 |
| 200 | 6 | 8 | 6 | | | | **8** | C = 100, B = 100 |
| 300 | 9 | 10 | 10 | 8 | | | **10** | C = 100, A = 100, B = 100 или C = 200, B = 100 |
| 400 | 12 | 13 | 12 | 12 | 9 | | **13** | C = 100, A = 200, B = 100 |
| 500 | 15 | 16 | 15 | 14 | 13 | 12 | **16** | C = 100, A = 300, B = 100 |

### Этап 3. Проекты A, B, C и D

В ячейках: $f_D(y) + F_3(x - y)$, где $F_3$ — результат этапа 2.

| Бюджет $x$ | D = 0 | D = 100 | D = 200 | D = 300 | D = 400 | D = 500 | $F_4(x)$ | Распределение |
|-----------:|------:|--------:|--------:|--------:|--------:|--------:|---------:|:--------------|
| 100 | 4 | 3 | | | | | **4** | D = 0 (остаток в A, B, C) |
| 200 | 8 | 7 | 4 | | | | **8** | D = 0 (остаток в A, B, C) |
| 300 | 10 | 11 | 8 | 9 | | | **11** | D = 100 (остаток 200 в A, B, C) |
| 400 | 13 | 13 | 12 | 13 | 10 | | **13** | D = 0, D = 100 или D = 300 |
| 500 | 16 | 16 | 14 | 17 | 14 | 13 | **17** | D = 300 (остаток 200 в A, B, C) |

### Этап 4. Проекты A, B, C, D и E (бюджет 500)

На последнем этапе нужен только бюджет 500, поэтому таблица состоит из одного столбца значений: $f_E(y) + F_4(500 - y)$.

| Вложено в E, $y$ | $f_E(y)$ | $F_4(500 - y)$ | Итого |
|-----------------:|---------:|---------------:|------:|
| 0 | 0 | 17 | 17 |
| 100 | 5 | 13 | **18** |
| 200 | 6 | 11 | 17 |
| 300 | 9 | 8 | 17 |
| 400 | 10 | 4 | 14 |
| 500 | 11 | 0 | 11 |

Максимум $F_5(500) = 18$ достигается при вложении 100 монет в проект E.

## Обратный ход

1. Этап 4: максимум 18 при $E = 100$. На проекты A, B, C, D остаётся 400 монет, $F_4(400) = 13$.
2. Этап 3, бюджет 400: значение 13 достигается при $D = 0$, $D = 100$ и $D = 300$. Выбираем $D = 0$, на A, B, C остаётся 400 монет, $F_3(400) = 13$.
3. Этап 2, бюджет 400: значение 13 достигается при $C = 100$. На A и B остаётся 300 монет, $F_2(300) = 9$.
4. Этап 1, бюджет 300: значение 9 достигается при $B = 100$, тогда $A = 200$.

## Ответ

$$
A = 200,\quad B = 100,\quad C = 100,\quad D = 0,\quad E = 100.
$$

**Максимальная суммарная прибыль: 18.**

Оптимальное решение не единственное. Если на шаге 2 обратного хода выбрать $D = 300$, на A, B, C останется 100 монет, $F_3(100) = 4$ достигается при $B = 100$ (или $C = 100$). Получаем, например, $B = 100$, $D = 300$, $E = 100$ с прибылью $4 + 9 + 5 = 18$.

## Проверка

Сумма вложений: $200 + 100 + 100 + 0 + 100 = 500$.

Прибыль по исходной таблице: $f_A(200) + f_B(100) + f_C(100) + f_D(0) + f_E(100) = 5 + 4 + 4 + 0 + 5 = 18$.
