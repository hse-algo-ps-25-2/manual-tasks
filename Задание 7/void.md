# Задание №7. Вариант 4

## 1. Постановка задачи

Дан ориентированный граф с вершинами A, B и C.

В графе имеются дуги:
- A → A;
- A → B;
- B → B;
- B → C;
- C → C.

Необходимо найти явную формулу количества маршрутов длины n, начинающихся в вершине A и заканчивающихся в вершине C.

Маршрут длины n содержит ровно n дуг. Прохождение петли считается одним шагом.

## 2. Система рекуррентных соотношений

Обозначим:

- A_n — количество маршрутов длины n из A в A;
- B_n — количество маршрутов длины n из A в B;
- C_n — количество маршрутов длины n из A в C.

Рассмотрим, каким образом можно попасть в каждую вершину на последнем шаге.

В вершину A можно попасть только из A:

A_n = A_(n-1).

В вершину B можно попасть из A или из B:

B_n = A_(n-1) + B_(n-1).

В вершину C можно попасть из B или из C:

C_n = B_(n-1) + C_(n-1).

Получаем систему:

A_n = A_(n-1),
B_n = A_(n-1) + B_(n-1),
C_n = B_(n-1) + C_(n-1).

Начальные условия для маршрутов длины 0:

A_0 = 1,
B_0 = 0,
C_0 = 0.

Поскольку из A в A можно пройти только по петле, получаем:

A_n = 1 при всех n >= 0.

Тогда:

B_n = 1 + B_(n-1).

При B_0 = 0 получаем B_n = n.

## 3. Сведение к одному рекуррентному соотношению

Из соотношения для C_n:

C_n = B_(n-1) + C_(n-1).

Следовательно:

B_(n-1) = C_n - C_(n-1).

Аналогично:

B_(n-2) = C_(n-1) - C_(n-2).

Используем соотношение:

B_(n-1) = A_(n-2) + B_(n-2).

Поскольку A_(n-2) = 1:

C_n - C_(n-1) = 1 + C_(n-1) - C_(n-2).

Получаем:

C_n = 2C_(n-1) - C_(n-2) + 1.

Чтобы получить однородное рекуррентное соотношение, запишем его для n-1:

C_(n-1) = 2C_(n-2) - C_(n-3) + 1.

Вычтем второе равенство из первого:

C_n - C_(n-1)
= 2C_(n-1) - 3C_(n-2) + C_(n-3).

Отсюда:

C_n = 3C_(n-1) - 3C_(n-2) + C_(n-3).

Это однородное линейное рекуррентное соотношение
третьего порядка с постоянными коэффициентами.

## 4. Характеристическое уравнение

Ищем решение в виде:

C_n = λ^n.

Подставляем в рекуррентное соотношение:

λ^n = 3λ^(n-1) - 3λ^(n-2) + λ^(n-3).

Разделим на λ^(n-3), где λ != 0:

λ³ - 3λ² + 3λ - 1 = 0.

Разложим многочлен:

(λ - 1)³ = 0.

Получаем единственный корень:

λ = 1.

Его кратность равна 3.

## 5. Нахождение явной формулы

Поскольку характеристическое уравнение имеет корень
λ = 1 кратности 3, общее решение имеет вид:

C_n = (a + bn + cn²) · 1^n.

То есть:

C_n = a + bn + cn².

Для определения коэффициентов используем начальные условия.

При n = 0:

C_0 = 0.

Следовательно:

a = 0.

При n = 1:

C_1 = 0,

поскольку прямой дуги из A в C нет.

Получаем:

a + b + c = 0.

Так как a = 0:

b + c = 0.

При n = 2:

C_2 = 1,

поскольку существует ровно один маршрут:

A → B → C.

Получаем:

a + 2b + 4c = 1.

С учётом a = 0:

2b + 4c = 1.

Решаем систему:

b + c = 0,
2b + 4c = 1.

Из первого уравнения:

b = -c.

Подставляем во второе:

-2c + 4c = 1.

2c = 1.

c = 1/2.

Следовательно:

b = -1/2.

Подставляем коэффициенты в общее решение:

C_n = -n/2 + n²/2.

Получаем окончательную формулу:

C_n = n(n - 1)/2.

## 6. Проверка результата

Проверим формулу для нескольких значений n.

n = 0:

C_0 = 0 · (-1) / 2 = 0.

Маршрутов длины 0 из A в C нет.

n = 1:

C_1 = 1 · 0 / 2 = 0.

Прямой дуги из A в C нет.

n = 2:

C_2 = 2 · 1 / 2 = 1.

Существует один маршрут:

A → B → C.

n = 3:

C_3 = 3 · 2 / 2 = 3.

Существуют три маршрута:

1. A → A → B → C.
2. A → B → B → C.
3. A → B → C → C.

Полученный результат совпадает с количеством маршрутов
на графе.

## 7. Ответ

Количество различных маршрутов длины n из вершины A
в вершину C равно:

C_n = n(n - 1)/2, n >= 0.

Формула получена путём составления системы взаимных
рекуррентных соотношений, сведения её к одному
однородному линейному рекуррентному соотношению
и решения соответствующего характеристического уравнения.
