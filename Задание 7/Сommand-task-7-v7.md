# Задание 7

### Дан ориентированный граф (Вариант 7):  
ﾠﾠﾠﾠﾠﾠﾠ┌┐ﾠﾠﾠﾠ ┌┐  
ﾠﾠﾠﾠﾠﾠﾠ↓ﾠ|ﾠﾠﾠﾠﾠ↓ﾠ|  
(A)ﾠ--> (C)ﾠ--> (B)

Маршрут длины 
n — это последовательность из n дуг графа; прохождение петли также считается одним шагом. Найдите количество различных маршрутов длины n, которые начинаются в вершине A и заканчиваются в вершине B.

## Решение: 

### Введём переменные:
a<sub>n</sub> - маршруты из А в А (длины n)  
b<sub>n</sub> - маршруты из А в B (длины n)  
c<sub>n</sub> - маршруты из А в C (длины n)  

### Составим рекуррентное соотношение:  
Чтобы попасть в вершину на шаге n, нужно на шаге (n-1) выйти из какой-то другой вершины.  

- Для a<sub>n</sub>: в вершину A не ведёт ни одна дуга, значит попасть в неё за n >= 1 шагов нельзя.  
**a<sub>n</sub> = 0** (при любых n >= 1)  

- Для b<sub>n</sub>: в вершину B можно попасть или из самой B (петля), или из C.  
**b<sub>n</sub> = b<sub>n-1</sub> + c<sub>n-1</sub>**  

- Для c<sub>n</sub>: в вершину C можно попасть или из самой C (петля), или из A.  
**c<sub>n</sub> = c<sub>n-1</sub> + a<sub>n-1</sub>**  
   
### Решим систему из трёх полученных уравнений:  
Так как a<sub>n-1</sub> = 0 (для всех n-1 >= 1, т.е. для n >= 2), то с<sub>n</sub> = с<sub>n-1</sub>

Рассмотрим несколько первых n:  

- n = 1:  
a<sub>1</sub> = 0  
b<sub>1</sub> = b<sub>0</sub> + c<sub>0</sub> = 0 + 0 = 0  
c<sub>1</sub> = a<sub>0</sub> + c<sub>0</sub> = 1 + 0 = 1 (маршрут A -> C)  

- n = 2:  
a<sub>2</sub> = 0  
b<sub>2</sub> = b<sub>1</sub> + c<sub>1</sub> = 0 + 1 = 1  (маршрут A -> C -> B)  
c<sub>2</sub> = c<sub>1</sub> = 1 = 1 (маршрут A -> C -> C)  

- n = 3:  
a<sub>3</sub> = 0  
b<sub>3</sub> = b<sub>2</sub> + c<sub>2</sub> = 1 + 1 = 2  (маршруты A -> C -> B -> B, A -> C -> C -> B)  
c<sub>3</sub> = c<sub>2</sub> = 1 = 1 (маршрут A -> C -> C -> C)  

Заметим, что любое c<sub>n</sub> = c<sub>n-1</sub> = 1. Это происходит потому что есть ровно один способ дойти до C за n шагов - сделать первый из A в С, а дальше n-1 раз пройти по петле.  
Таким образом, b<sub>n</sub> = b<sub>n-1</sub> + 1 (для n >= 2).  

Доработаем уравнение:  
b<sub>n</sub> - b<sub>n-1</sub> = 1  
b<sub>n+1</sub> - b<sub>n</sub> = 1 (то же уравнение, но для шага n+1)  
Вычтем из второго первое:  
(b<sub>n+1</sub> - b<sub>n</sub>) - (b<sub>n</sub> - b<sub>n-1</sub>) = 1 - 1  
b<sub>n+1</sub> - 2b<sub>n</sub> + b<sub>n-1</sub> = 0 (теперь это однородное линейное рекуррентное соотношение)

### Составим и решим характеристическое уравнение:  
b<sub>n+1</sub> - 2b<sub>n</sub> + b<sub>n-1</sub> = 0  

Заменим b<sub>n</sub> на λ<sup>n</sup>:  
λ<sup>n+1</sup> - 2λ<sup>n</sup> + λ<sup>n-1</sup> = 0  

Разделим на λ<sup>n-1</sup> (λ != 0):  
λ<sup>2</sup> - 2λ + 1 = 0  

Решим квадратное уравнение:  
(λ - 1)<sup>2</sup> = 0

Один корень двойной кратности: **λ = 1**

### Найдём формулу для числа указанных маршрутов:  
Так как характеристическое уравнение имеет корень двойной кратности, общее решение будет иметь вид:  

b<sub>n</sub> = A<sub>1</sub> * λ<sup>n</sup> + A<sub>2</sub> * λ<sup>n</sup> * n  
Для нашего случая (λ = 1): b<sub>n</sub> = A<sub>1</sub> + A<sub>2</sub> * n  

Найдём константы A<sub>1</sub> и A<sub>2</sub>, для этого вспомним первые b<sub>n</sub>:

b<sub>1</sub> = b<sub>0</sub> + c<sub>0</sub> = 0 + 0 = 0  
b<sub>2</sub> = b<sub>1</sub> + c<sub>1</sub> = 0 + 1 = 1

Подставим n = 1 и n = 2 в общее решение:  
0 = A<sub>1</sub> + A<sub>2</sub> * 1  
1 = A<sub>1</sub> + A<sub>2</sub> * 2  

Получим:  
A<sub>1</sub> = -(A<sub>2</sub>)  
-(A<sub>2</sub>) + A<sub>2</sub> * 2 = 1  

Значит:  
A<sub>1</sub> = -1  
A<sub>2</sub> = 1  

Подставим константы в общее решение:  
b<sub>n</sub> = (-1) + 1 * n = **n - 1**

### Ответ:  
Количество различных маршрутов длины n, которые начинаются в вершине A и заканчиваются в вершине B: **n - 1**

### Проверка:  
Считаем для n = 4 по формуле:  
b<sub>4</sub> = 4 - 1 = **3**

Считаем руками:
- n = 4:  
b<sub>4</sub> = b<sub>3</sub> + c<sub>3</sub> = 2 + 1 = 3  
Маршруты:  
A -> C -> B -> B -> B,  
A -> C -> C -> C -> B,  
A -> C -> C -> B -> B.

Всё сходится!
