# Задание №7
## Маршруты в ориентированном графе и взаимные рекуррентные соотношения

### Вариант 1. Команда cherepaha.

## Условие

Граф:

```mermaid
graph LR
    A((A)) --> C((C))
    B((B)) --> C
    C --> B
```

Найти явную формулу для числа маршрутов длины $n$, которые начинаются в $A$ и заканчиваются в $B$. Петель нет.

## Обозначения

$a_n$, $b_n$, $c_n$ — число маршрутов длины $n$, которые начинаются в $A$ и заканчиваются в $A$, $B$, $C$. Ищем $b_n$.

## Система соотношений

Маршрут, который на шаге $n$ заканчивается в вершине, приходит в неё по дуге из той вершины, где он был на шаге $n-1$. Число маршрутов в вершину складываем по всем входящим дугам:

$$a_n = 0, \qquad b_n = c_{n-1}, \qquad c_n = a_{n-1} + b_{n-1}.$$

В $A$ дуг не входит, в $B$ приходит только $C \to B$, в $C$ — $A \to C$ и $B \to C$.

Начальные условия считаем по дугам из $A$: в $B$ за один шаг не попасть, $b_1 = 0$; за два шага — ровно один маршрут $A \to C \to B$, $b_2 = 1$.

## Сведение к одному соотношению

При $n \ge 2$ имеем $a_{n-1} = 0$, поэтому $c_n = b_{n-1}$; сдвигая номер, $c_{n-1} = b_{n-2}$ при $n \ge 3$. Подставляем в $b_n = c_{n-1}$:

$$b_n = b_{n-2} \qquad (n \ge 3).$$

Получилось однородное линейное рекуррентное соотношение с постоянными коэффициентами, глубина 2.

## Характеристическое уравнение

Ищем решение вида $b_n = r^n$. Подставляем в $b_n = b_{n-2}$:

$$r^n = r^{n-2} \;\Rightarrow\; r^2 = 1 \quad (r \ne 0),$$

корни $r_1 = 1$, $r_2 = -1$ — разные. Поэтому

$$b_n = A \cdot 1^n + B \cdot (-1)^n = A + B(-1)^n.$$

Константы находим по начальным условиям:

$$b_1 = A - B = 0, \qquad b_2 = A + B = 1 \;\Longrightarrow\; A = B = \tfrac{1}{2}.$$

## Ответ

$$b_n = \frac{1 + (-1)^n}{2}.$$

Маршрутов из $A$ в $B$ ровно один при чётном $n$ и ноль при нечётном.

## Проверка

По формуле $b_3 = \frac{1-1}{2} = 0$. Единственный маршрут длины 3 — $A \to C \to B \to C$, заканчивается в $C$, в $B$ не попадает. Совпадает.

$b_4 = \frac{1+1}{2} = 1$. Единственный маршрут длины 4 — $A \to C \to B \to C \to B$, заканчивается в $B$. Совпадает.

Из каждой вершины выходит ровно одна дуга, поэтому маршрут из $A$ единственен на любой длине: $A, C, B, C, B, \ldots$ — попадает в $B$ ровно на чётных шагах. Формула это даёт.
